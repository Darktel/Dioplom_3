# Dioplom_3
Репозиторий дипломной работы по автоматизации UI веб-приложение Stellar Burgers. 

Запуск тестов:
Если нужно запустить тесты в браузере Chrome. 

    mvn -Dbrowser=chrome clean test

Если запуска без параметров. То будет по умолчанию браузер Firefox.

    mvn clean test    

Для каждого теста создается клиент. И соответственно удаляется после теста. Получилось немного избыточно, 
так как вызывается удаление пользователя которых даже не был создан (для негативных тест-кейсов).
